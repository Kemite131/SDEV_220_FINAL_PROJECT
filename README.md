# Employee Management System

This project is a Python desktop application created for Silver Oak Tech Solutions.

The system will allow users to:

- Add employee records
- Search for employees
- Update employee information
- Delete employee records
- Record attendance
- Display all employees

The application will use Python, Tkinter, classes, lists, dictionaries, and tuples.

The repository contains my completed Employee Management System developed with Python and Tkinter. The system includes employee record management, attendance tracking, JSON data storage, multiple classes, and the required collections. The program has been tested and runs without syntax or runtime errors.
